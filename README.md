# 像素勇者 · Pixel Quest

一款像素风**双形态**游戏：**18 个小关是 16 种互不重复的独立单屏街机小游戏**（扫雷/打地鼠/点灯/记忆翻牌/
推箱子/贪吃蛇/矿脉寻宝/落块筑墙/弹幕生存/编钟/泡泡消除/迷宫追逃/垂直攀跃/打砖块/幽冥炮台/回响节拍；
矿脉与弹幕各有一个进阶变体），**13 个 Boss 关是横版平台动作 Boss 战**（三张地图、14 只 Boss）。零依赖、零素材文件——
所有像素画、瓦片、背景、音效与音乐全部由代码生成，双击 `index.html` 即玩，可离线、可上 GitHub Pages。

> 📖 **打不过 Boss？** 看这里：[Boss 图鉴（玩家向）](docs/boss-guide.md)——14 只 Boss 全部招式的效果与躲法。

## 玩法

- **31 关 · 18 街机小关 + 13 Boss 关（v30 后三章插入间奏）**：选关屏按章分五屏
  （Tab/Q/E 或 1~5 切章），全部按钮与 Boss 仍在同一屏；
  点进小关不再进入横版地图，而是直接开一局独立街机游戏（`arcade.js`，固定 384×224 单屏）。
  小关与 Boss 交替推进：L1~L6 街机 → L7 Boss → L8~L12 街机 → L13 Boss → L14~L15 街机 →
  L16 Boss → L17 街机 → L18 Boss → **L19 街机间奏** → L20 Boss →
  L21 Boss → **L22 街机间奏** → L23~L24 Boss → **L25 街机间奏** → L26~L27 Boss →
  L28 Boss → **L29 街机间奏** → L30~L31 Boss。后三章最多连打两只 Boss，
  地图一终章 → 地图二 → 地图三的 Boss 一只不少，Boss 关保留原有平台动作与全部招式。
- **18 关 16 种玩法（v27/v30）**：v26 的 14 关只有 8 种类型、6 对重复；v27 把重复的那 6 关各换掉一个，
  现在一关一个类型——动作扫雷、打地鼠、点灯、记忆翻牌、推箱子、贪吃蛇、矿脉寻宝（钩爪抓宝石）、
  落块筑墙（俄罗斯方块）、弹幕生存（躲陨星收星屑）、编钟（五音 Simon）、泡泡消除（同色三连）、
  迷宫追逃（BFS 鬼差）、垂直攀跃（无限向上跳）、打砖块；v30 又加 **幽冥炮台**（转炮打鬼火/避魂雷）
  与 **回响节拍**（缩环进金环敲拍），并给矿脉/弹幕各做一个进阶变体（L25 喉中拾遗、L29 镜海流星）。
  每关有独立 par 时间与奖励币上限，沿用三星/解锁/皮肤存档，但不再有横版跑图、敌人或封印门。
- **18 关难度加码（v29/v30）**：用户嫌普通关「太无聊」，18 关统一加大盘面/加快节奏：9×6 扫雷 12 雷、
  5×5 点灯 10 次打乱、16 张记忆牌、双箱推箱子、10 果贪吃蛇 + 石柱、7 颗宝石 + 5 翡翠 3 石、
  6 行俄罗斯方块、40 秒弹幕 + 10 星屑、6 轮编钟、150 颗泡泡、0.40s/格的鬼差、1200 尺攀跃、
  6 行砖墙 + 46px 挡板 + 球速 168；新增间奏为 8 只鬼火 / 10 拍 / 8 宝石 6 翡翠 5 石 / 45 秒 12 星屑。
  `tools/_v29_arcade_reach.js` 用**真实输入**逐关证明 3 个种子都能
  自然通关（不调用 `_forceWin`），并做「空输入 25 秒不会自己赢」的负例。
- **地图二：威胁从玩家身上长出来（v20）**：地图一的招式都是「Boss 打你、你躲」，玩家的动作恒为躲/打。
  再做第七只必然重复，所以地图二换了框架——**五只 Boss 只读玩家自己的行为再惩罚**，每只问一个问题：
  地图二五只血量全部对标牛魔王（540/540/720/660/630），轮转池**没有公共弹幕**（v22 例外：喉的远程池
  找回万弹穿云压远程）——
  轮到的每一下都是它自己的招牌；它们还会主动朝你挪步（idle/收招期都走，不再罚站），
  P2 各有一条自己的獠牙（烬烧更狠 / 秤更敏感 / 茧喂更快 / 喉嘴更大 / 钟越打越急）。
  - **余烬回响**（L21）问「你打得多快」：伤害被它记成**热量**，热量越高引燃越疼，满了当场烧穿自己。
    全作第一次要求玩家**停手**（停 2.5s 清空）；v22 起引燃先落 **0.55s 预警圈**再爆——跑得掉。
  - **双生天秤**（L23）问「你一直从哪边打」：**自己穿身**到另一边承伤 ×1.25；站桩连击到 3 次触发失衡——那一击只吃 2 折、破绽窗口被它晃没。
    解法是**穿到另一边**——而它会把位置和你对调，把这一招当场反将一军。
    v22 提伤：砝码/横梁 ×2，P2 砝码变**四连宽扇**，新招**衡权压顶**（追踪点杀，落点锁你脚下）。
  - **孵化之间**（L24）问「你什么时候打」：虫卵每 3s 进化一级，打碎只让它**提前一格**（卵→幼虫），
    等成虫再打才掉能量核。打早了是净亏。v22 新招**破茧亲卫**（周期召甲虫），
    茧网加宽到 112px 且**不可打掉**——躲法只剩别踩。
  - **无声之喉**（L26）问「你用什么打」：吸气把弹体吞进嘴里变成自己的血；喂多了它会**反刍**成弹幕。
    打它张开的嘴能引爆积食——喂得越狠、爆得越疼。玩家的动作变成**挑窗口**。
    v22 反远程：吸气圈 120→170、拽力 60→74、咬圈 34→46，远程池找回**万弹穿云**。
  - **终末之钟**（L27）问「你现在能打吗」：v22 改**五音谱**——宫·审判摆锋 / 商·丧钟轰鸣 /
    角·天罚重锤 / 徵·双锤坠狱 / 羽·追魂余音，五拍一轮接 3.2s **休止**；
    非休止拍**完全免伤**，休止符是唯一输出窗口（每段血 210，对标牛魔王）。
    第一轮瞎躲，第二轮就能背下来。摆锋半径 78→112、摆速 ×1.5；v23 再改 **360° 整圈扫描**——
    绕到背后不再安全，躲法只剩「跑出金圈」或「冲刺无敌帧穿过摆臂」。
  - 五只招牌**不产生新弹种**，新增的十个普通招（激光/火鞭/换位/横梁/蛛网/虫群/咬/钟摆/声波/钟锤）
    逐个避开地图一已用的 26 种交互。`tools/_v20_boss_test.js` 用交集矩阵把这条钉死。
- **地图三·终焉镜海（v28）**：前两张地图问「你怎么打」「你怎么读招」，地图三把问题换成
  **「你自己怎么动」**——三只 Boss 的解法都写在玩家的动作里，参照的是别的优秀游戏最狠的那条规则：
  - **律动·俄耳甫斯**（L28）问「你踩不踩拍」：头顶节拍器 1.15s 一拍，拍点 ±85ms 内命中 **×2 伤害**
    并累积拍点，连中 4 拍直接破防；失拍 ×0.7 且拍点清零。招牌**断奏**（4 发追踪单音，间隔 0.16s）/

    碎镜片可以硬打（每片 4 下），但更快的是用冲刺无敌帧**主动撞碎粉色镜弹/镜墙**——每碎一枚直接扣 5% 总血，
    三枚全碎 → 1.2s 破绽 + 2s 破防，16s 后重铸。招牌**棱镜散射** / **镜雨** / **镜墙推进**——墙只能冲刺穿过，
    绕着走只会被顶开。
  - **终焉·阿刻戎**（L31）问「你敢不敢停」：凝视槽站定上涨（16/s）、移动/跳跃/冲刺回落（26/s），
    满槽强制落**石化光柱**（P2 一根变三根 ±44px）。招牌**贯目之光**（12px 竖光带 60px/s 缓慢追扫，
    跑速 120 甩得开）/ **裂界石牙**（四根石刺依次从脚下冒出）/ **陨石雨**（五连砸落）。
  - 三只都吃充能大招，空旷场各摆了 3 只史莱姆当充能饲料；伤害最多 2 心，全部走既有护盾/无敌帧口径。

### v7.4 谜题可通关性护栏（"不做无法通过的游戏"）

v7.3 的谜题门要求「本关神龛全解」才放行终点，于是**谜题不可解 = 整关不可通关**。四层护栏：

1. **数据层**：`node tools/gate.js puzzle` 对 13 题逐题做唯一解计数（数织走行线索枚举+列前缀剪枝，
   数独走 MRV 回溯），并断言每关神龛都有可玩数据——改坏数据直接红。
2. **判定层**：胜负按**规则**判（数独=行列宫合法排列，数织=行列线索吻合），不再逐格对答案。
   将来引入多解题，玩家推出的任一合法解都能过，不会"明明解对了却判错"。
3. **兜底层**：数据不可玩时神龛按已解处理（fail-open，只在本次会话生效、不写档不发奖），
   开龛被拒，谜题门自动放行；`frame()` 捕获单帧异常并继续主循环（一次渲染越界不再永久冻死整局）；
   `?level=abc` 等非法参数回落第 1 关。
4. **能力层**：H 键逐格提示，无限次——不会做也能一格一格点过去。
   v7.5 起每格 -1 金币（金币为 0 时免费照给、不扣成负数）：既保留"必可通关"，又不至于一键白送。

### v7.5 可达性护栏（"走得到"与"解得开"是两件事）

v7.4 只证明了谜题数据可解，没证明玩家**走得到**神龛——神龛悬在虚空、卡在实心块后、或高出最大跳跃
高度时，谜题再完美也白搭。`tools/reach.js` 补上这一环：

- **不做弧线估算，直接驱动 `updateWorld` 跑真物理**。节点 = 地面落脚点，每个节点展开一组宏动作
  （等待 / 走 / 跳×跳跃高度×二段跳时机×冲刺时机 / 空中反向 / 风柱内多段变速），落地即新节点，
  A\* 按到目标的距离挑节点。二段跳、冲刺、弹簧、风柱、移动平台、拉杆开关砖、传送门全部走真实代码路径。
- **witness 即证据**：搜到路径后，把帧级按键序列在**全新关卡实例**上原样回放，能再次命中才算 PASS。
  回放失败只报 WARN，不谎报通过。
- 抽象边界：敌人/锯齿/炮台/吊灯摆锤被清空（可击杀或可躲避的周期障碍，不构成几何阻断）；
  尖刺与熔岩保留真实伤害，路径累计扣血 ≥ 5 判为致命；按键以固定 60Hz 注入。
- 当前结果：**26/26**（13 神龛 + 13 终点）全部命中并回放验证，耗时约 17s。

顺带查出并修掉一个真 bug：`engine.js` 的 `solid()` 不认传送带 `(` / `)`，而 `levels.js` 的 STAND 集合认
——L4 把传送带铺在地面行，于是那 8 格画着地板的传送带是**无底洞**，踩上去直接掉出地图；
"逆行传送带"这个机制此前从未真正生效。两处口径统一后传送带既能站立也能推人。

### v7.6 三方口径统一（"看得见的必须能碰，碰得到的必须看得见"）

一个瓦片/实体在引擎里有四套口径：**渲染表**（`renderTiles` 的 `switch`）、**碰撞表**（`solid()`）、
**伤害表**（hazard 判定）、**静态断言集**（`SOLIDISH` / `STAND`）。任一分叉就长出「隐形墙」或
「看得见没反应」。用两个审计脚本（`_audit_tiles.js` / `_audit_ent.js`）把四套表逐格对拍，修掉 8 项：

| 缺陷 | 现象 | 修法 |
|---|---|---|
| `'B'` 木箱不绘制（16 关 80 处） | 实心但全不画 = **一面看不见的墙** | `renderTiles` 补 `case 'B'`，缺素材回落 block+裂纹 |
| 敌人站单向平台 `'='` 掉落 | L6/L14 90 帧掉 80px / 318px | 敌人落地补单向平台（同玩家 `standOn` 口径） |
| 蝙蝠巡逻不查墙 | 31 只里 7 只整只飞进墙内，300 帧嵌墙 543 帧 | 前方探测 + 撞墙钳位掉头；正弦浮动也查 |
| 炮台炮口被木箱堵 | 子弹最大飞行 9px | 开火前 6 格净空检查，被堵不开火（砸箱自动恢复） |
| 魂火自爆判定 30px | 精灵仅 10×10，视觉没碰到就掉血 | 半径 30→16，改「爆心到玩家矩形最近点」 |
| 弹簧触发带高 10px | 脚底偏移 -12~+14 都触发 | 收紧到精灵可视 `[s.y-2, s.y+6]`，用本帧扫掠区间防快落漏判 |
| 移动平台行程写死 ±56 | L3 平台压穿 7 格 / 2 格墙 | 构造期沿轨道扫 `_railSolid` 截断行程 |
| `_railSolid` / `SOLIDISH` 缺字符 | 电锯与静态断言跟 `solid()` 分叉 | 各补 `'G' '(' ')'` |

同批给数织/数独补了**规则说明**：首次进入弹一次性规则卡（任意键关 / 8s 超时自动关，永不卡死），
之后盘面右侧常驻三行速查（数织「线索=连续黑格段长，段间至少空一格」/ 数独「行列宫各一次」）。

### v10 血量三倍 + Boss 招式重做（"它只会那几招"的根因是轮转游标漂移）

### v11 终点封印（"跑到终点就通关"的漏洞）

玩家反馈「小关可以什么都不干直接位移到最后」。查代码确认：终点判定只有
`if (aabb(p, goal)) levelClear()` —— **碰到旗就过关，零前置条件**，敌人、金币、神龛全都可以绕过。

| 项 | 做法 |
|---|---|
| **封印条件** | 三条路**任选其一**：击败 60% 敌人 / 收集 40% 金币（按枚数）/ 解开本关神龛 |
| **为什么三条** | 单条会卡人（某个金币在难跳的支线、某个敌人藏死角）。三条路保证任何玩家都能用自己擅长的方式推进 |
| **为什么不通关而不是挡路** | 封印**不加任何物理碰撞**，只拦 `levelClear()`。`reach` 门禁判定的是「玩家矩形物理命中终点」，加碰撞会让 27/27 直接归零 |
| **Boss 关** | 豁免（Boss 本身就是目标） |
| **防卡关** | 死亡 ≥5 次后门槛各降 20%（只降一次）——封印是引导体验，不是惩罚玩家 |
| **视觉** | 终点前紫色能量墙 + 锁；靠近 96px 出条件面板（三条线同列，达成行变金 + ✓）；被弹回时整墙转红 + 冲击环 |

实机验证：未解时冲终点 `state` 仍是 `play`（被拦）；三条路各自解锁后 `state` 变 `clear`；
4 个 Boss 关 `open=true via=boss`；`reach` 保持 **27/27**。

### v12 Boss 七种交互类型 + 第 19 关牛魔王（"招式多但类型单薄"）

玩家带回来的原话是「boss 没啥意思」。数了一下：v10 之后每只 Boss 有 8~10 招，但**应对动作只有一种**
——看预警、走开。招式再多也是同一个动作的重复，第二次打就能背板。

去拆了造梦西游的 Boss 设计，可以复用的不是"招式表"，是**每招逼你做不同的正确动作**：
跳、绕、转火、清小怪、打断、进圈、别站正面。照着这个思路重做了一轮：

| 类型 | 你要做的事 | 为什么不再是"走开" |
|---|---|---|
| 多段连撞 | 往场地**中间**绕 | 撞墙/跑满行程都会**反弹续冲**，贴墙躲反而被夹死；段数用完才是破绽 |
| 召唤回血 | **先清小怪** | 召唤体存活时 Boss 每秒回血（封顶当前段），不清就是白打 |
| 蓄力全屏 `quell` | **打断** 或 **站进结界圈** | 两条路都成立：打满 12 点伤害 → 打断进 1.2s 破绽；没打断就吃全屏 2 伤（圈内免疫） |
| 抓取摔投 `grab` | 离开正前方 46px | 惩罚无脑贴脸输出，逼你走位而不是站桩 |
| 劈地波 `quake` | **跳** | 26px 高、14px 窄，单跳 53px 稳过；和"贴地波"是两种动作 |
| 火柱 `pillar` | 离红圈 + 绕开柱体 | 红圈只是预告，柱升起后 2.5s 变成**持续危险区**，改变场地形状 |
| 核心护盾 `core` | **转火打核心** | 本体免伤，2 颗核心各 3 血打光 → 2s 大破绽；打错目标等于白打 |

分配：L7 星核巨兽（撞/抓）、L13 蛟龙（震/召）、L16 判官（蓄力全屏）、L18 双 Boss（撞/震/核心/抓/蓄力），
新增 **L19 火焰山·牛魔王**（kind 6，hp 630、56×48，蛮力型：三段撞 + 抓取 + 火柱 + 召唤回血 + 劈地）。

实机踩出来并修掉的三件事（都写进 CONTRACT 了）：
1. **结界点/核心原本放在场地 25%/75% 列，距 Boss 576px，相机跟玩家不跟 Boss → 全在镜头外**，
   玩家根本看不见安全区和该打的目标。改成结界在玩家左右各 120px、核心在 Boss 两侧 ±150px，同屏可见。
2. **boss6 没配 `quell`/`core` 参数对象**，进对应状态直接抛 `Cannot read properties of undefined`，
   主循环每帧报错。所有 Cast 态现在都有 `T.xxx || BAL.<参考表>.xxx` 兜底。
3. **顶栏长关卡名压住金币图标**（L19 原名 150px vs 金币在 x=100），顶栏文字区裁到 96px + 名字缩短。

**45 条断言全过**（每招可躲性逐条验：背后不中抓 / 起跳不中波 / 圈内 0 伤 / 打断转破绽 / 核心破光转 2s 破绽）、
