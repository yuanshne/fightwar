# 像素勇者 · Pixel Quest

一款类超级马里奥的**像素风横版闯关平台游戏**，带轻动作要素（参考《闪翼双星》手感与《冒险王》的
Boss 战模式）。零依赖、零素材文件——所有像素画、瓦片、背景、音效与音乐全部由代码生成，
双击 `index.html` 即玩，可离线、可上 GitHub Pages。

## 玩法

- **24 关 · 12 套主题**：草原 → 幽暗洞窟 → 天空栈道 → 齿轮工厂 → 烈焰深渊 → 最终之塔（纵向登顶）
  → BOSS·星核巨兽 → 星空回廊 → 落日王城 → 龙宫外海 → BOSS·蛟龙敖渊 → 幽冥鬼道 → BOSS·幽冥判官
  → **纯纵向攀爬关** → **终章双 Boss** → **BOSS·烈焰·牛魔王（v12）**
  → **地图二·回响之厅（v20：L20~L24 五关全 Boss，无小怪供给，装备全靠这五场）**
- **地图二：威胁从玩家身上长出来（v20）**：地图一的招式都是「Boss 打你、你躲」，玩家的动作恒为躲/打。
  再做第七只必然重复，所以地图二换了框架——**五只 Boss 只读玩家自己的行为再惩罚**，每只问一个问题：
  地图二五只血量全部对标牛魔王（540/540/720/660/630），轮转池**没有公共弹幕**——
  轮到的每一下都是它自己的招牌；它们还会主动朝你挪步（idle/收招期都走，不再罚站），
  P2 各有一条自己的獠牙（烬烧更狠 / 秤更敏感 / 茧喂更快 / 喉嘴更大 / 钟越打越急）。
  - **余烬回响**（L20）问「你打得多快」：伤害被它记成**热量**，热量越高引燃越疼，满了当场烧穿自己。
    全作第一次要求玩家**停手**（停 2.5s 清空）。
  - **双生天秤**（L21）问「你一直从哪边打」：**自己穿身**到另一边承伤 ×1.25；站桩连击到 3 次触发失衡——那一击只吃 2 折、破绽窗口被它晃没。
    解法是**穿到另一边**——而它会把位置和你对调，把这一招当场反将一军。
  - **孵化之间**（L22）问「你什么时候打」：虫卵每 3s 进化一级，打碎只让它**提前一格**（卵→幼虫），
    等成虫再打才掉能量核。打早了是净亏。
  - **无声之喉**（L23）问「你用什么打」：吸气把弹体吞进嘴里变成自己的血；喂多了它会**反刍**成弹幕。
    打它张开的嘴能引爆积食——喂得越狠、爆得越疼。玩家的动作变成**挑窗口**。
  - **终末之钟**（L24）问「你现在能打吗」：四拍固定曲谱（钟摆→声波→钟锤→**休止**），
    非休止拍**完全免伤**，只有休止符的 3s 是输出窗口（每段血 210，对标牛魔王）。
    第一轮瞎躲，第二轮就能背下来。
  - 五只招牌**不产生新弹种**，新增的十个普通招（激光/火鞭/换位/横梁/蛛网/虫群/咬/钟摆/声波/钟锤）
    逐个避开地图一已用的 26 种交互。`tools/_v20_boss_test.js` 用交集矩阵把这条钉死。
- **Boss 七种交互类型（v12）**：不再只是「看红圈走开」——多段连撞（撞墙/跑满行程反弹续冲，得往中间绕）、
  召唤回血（小怪活着 Boss 每秒回血，先清怪）、蓄力全屏（**打断**或站进**结界圈**二选一）、
  抓取摔投（别站正前方 46px）、劈地窄高波（跳）、火柱（红圈升起后变成持续危险区）、
  核心护盾（本体免伤，转火打掉 2 颗核心才破盾 → 2s 大破绽）
- **Boss 三段血（v8.0）**：血条三等分，**血量是连续掉的**——跨过 66% / 33% 只播「阶段切换」
  演出（击破飘字 + 清屏弹幕 + 0.9s 假死）并解锁末段新招进狂暴；**只有你死掉才会回退**：
  复活时正在打的这段血条回满（打到 49% 死 → 回 66%，打到 80% 死 → 回 100%），已跨过的段保留。
  死一次只丢一段进度，不用重打整场
- **Boss 门前检查点（v8.0）**：终章在 Boss 门口（x≈62）有一处，死了当场复活，
  不用再从开局点空跑 1000px
- **终章双 Boss（v7.9）**：最后一关先后迎战 **冥古龙**（骨角破翼，熔岩裂纹；炼狱吐息/陨落）与
  **曜光·圣裁者**（圣袍光环光翼；圣辉轮/传送）；第一棒倒下不是通关，第二棒原地降临
- **15 种机关**：弹簧、单向平台、移动平台（可载人）、崩塌砖、尖刺、熔岩、拉杆切换橙/蓝砖、
  钥匙与门、传送带、大炮、横/竖电锯、冰面、检查点、**可碎木箱**（J 攻击打碎出金币）
- **动作系统（v2）**：攻击（J/X，顿帧+震屏）、冲刺（K/Shift，残影尾迹+免疫传送带）、
  连击计数（2s 窗口，HUD 弹字）；敌人可踩踏可斩击，炮弹可斩碎
- **闪避无敌帧（v7.9 → v15 定版 0.20s）**：冲刺起手 **0.20s** 无敌（12 帧；v7.9 是 0.10s=6 帧，
  v14 加到 0.15s 后仍偏难，v15 定在 0.20s）——覆盖一次冲刺时长的 71%，弹幕/连撞/劈地波能一口气穿过去；
  连按 K 仍留 0.30s 裸窗（CD 0.5s），不会变成滚地无敌。与受伤无敌走同一套判定，尖刺/熔岩/贴地波同样覆盖
- **幽冥关可读性（v8.0）**：nether 黑暗层光圈 64→110、灯笼 80→130（纯纵向关的对面墙终于看得见）；
  暗处可落脚平台的顶边带一条缓慢呼吸的绿光，一眼分得出"哪块能站"。关卡提示条改为 3 秒淡出
- **三技能 + HP（v3）**：U 星陨术（三连星 AoE，8s CD）、I 星光护盾（3s 内吸 2 次伤害，**连尖刺/熔岩/电锯也挡**，12s CD）、
  O 流星连斩（连击≥8 充能的全屏大招，20s CD）；玩家 5 颗心 HP + 无敌帧 + 击退，敌人掉回复心
- **双角色（v19）**：除近战勇者外新增 **星语法师**（C 键切换，存档持久化）。法师普攻是带
  微追踪的奥术飞弹，U/L 都是远程（穿透冰矛 / 三枚追踪弹），O 是全屏陨星风暴；代价是 **4 心**
  与**法力槽**——普攻命中/击杀回蓝，技能耗蓝，法力不足只提示、不进 CD、不吞输入。
  骑士全部数值与手感一个字节没动，两角色共用同一套跳跃/冲刺物理
- **护盾吸收 = 一次真实受击（v8.2 修复）**：此前吸收命中不给无敌帧，敌人贴身或弹幕穿身时
  伤害逐帧判定，2 层吸收 2 帧内打光、第 3 帧人照样掉血——观感就是"盾一碰就碎"。现在吸收命中
  与正常受击同口径：**1s 无敌帧 + 击退弹开 + GUARD 飘字 + 青白粒子 + 抖屏**，一次吸收真的只吃一下
- **谜题神龛（v4）**：前六关各藏一座石碑，走近按 ↑ 开谜——**奇数关数织**（5×5 花 → 7×7
  史莱姆 → 10×10 Boss 脸，解出来就是像素画）、**偶数关数独**（4×4 → 6×6 → 9×9 唯一解）；
  **不强制**——不解也能直接通关；解开得 +5 金币 + **必掉 1 件当关档位装备**（优先补你最弱的槽位），
  神龛点亮并把谜底挂在头顶，进度持久化
- **小关不再是直线跑道（v8.0）**：此前第二章两关只有 2 个气流机关、第三章小关机关数为 0，
  5 个小关都是「跑图 + 稀疏几个怪」。现在每关补 2~3 种引擎早已实装却没被摆出来的机关
  （吊灯摆锤 / 骑士 / 幽焰法师 / 传送门 / 风柱），机关与敌人**组合出题**而不是各自演示一遍，
  并各藏一个可选挑战房（宝石 + 金币 + 木箱，死路可原路返回）
- **吊灯锤加了危险框（v8.0）**：12×12 的金框锤和 8×8 的金币在亮色背景下几乎同款，
  现在锤头外包一圈橙红呼吸框、链条加粗——一眼分得出「能吃」和「能砸死你」
- **手感三件套**：土狼时间 0.12s、跳跃缓冲 0.18s、可变跳高（松键截断）；单跳 53px（3.3 格）、二段跳 95px；
  高刷屏输入零丢失（144Hz 实测 0%）
- **美术（v2.5）**：全素材 ≥4 色阶+棋盘抖动、彩色描边（零纯黑）、三层视差背景、
  30 种主题装饰、发光裂纹/符文等材质母题
- **星级**：★通关 / ★金币全收 / ★限时；进度与设置 localStorage 持久化
- **音频**：WebAudio 实时合成 21 个音效 + 双轨循环 BGM（M 键开关）

## 操作

| 键 | 功能 |
|---|---|
| ←→ / A D | 移动 |
| ↑ / W / 空格 | 跳跃（长按更高）；神龛旁=开谜题 |
| J / X | 攻击（可碎木箱/斩炮弹/连击）；谜题内=填格 |
| K / Shift | 冲刺（残影尾迹）；谜题内=叉格 |
| H | 谜题内=提示一格（**无限次**，不会做也能一格一格点过去；每格 -1 金币，金币为 0 时免费照给、不阻断） |
| U / I / O | 勇者：星陨术 / 星光护盾 / 流星连斩（充能大招）　·　法师：冰晶长矛 / 星辉屏障 / 陨星风暴（充能大招） |
| L | 勇者：星刃回旋（去回两程）　·　法师：追星弹（三枚自动追踪） |
| C | 角色选择（标题屏 / 选关屏可开；确认后下一关生效） |
| 方向+数字 | 谜题内导航与填数　·　P/R/Esc 暂停/重开/菜单　·　M 声音 |

**全界面键位等价（v8.0）**：标题 / 选关 / 背包 / 衣橱 / 谜题 / 结算的导航一律 `方向键 ≡ WASD`，
确认一律 `Enter ≡ 空格`。任何界面都不需要记住两套键位。

第一关的操作提示**常驻在天空背景上**（半透明 + 深色投影，不遮挡地面与敌人），不会 3 秒后消失。

engine.js       物理(逐轴AABB/土狼时间)、15种机关、敌人AI、攻击/冲刺/连击/顿帧、世界状态

tools/gate.js   确定性门禁：art=语法+导出 / levels=执行+断言 / engine=逐关构造+空转180帧
                / puzzle=谜题可解性 / reach=神龛与终点的物理可达性
tools/puzzle_audit.js  谜题审计模块（数织/数独唯一解计数 + 神龛↔PUZZLES 配对），gate 与 CLI 共用

开发流程（详见 `docs/`）：brainstorm 方案 → grilling 拷问 → **GLM-5.3 设计/测试 + GLM-5.3-Flash

v2 迭代实测记录：高刷跳跃输入丢失 50%→0%、修复两个"看似正常实则过不去"的关卡阻断 bug
（L5 弹簧岛缺失 / L6 之字爬超高）。

### v7.4 谜题可通关性护栏（"不做无法通过的游戏"）

v7.3 的谜题门要求「本关神龛全解」才放行终点，于是**谜题不可解 = 整关不可通关**。四层护栏：

1. **数据层**：`node tools/gate.js puzzle` 对 13 题逐题做唯一解计数（数织走行线索枚举+列前缀剪枝，
   数独走 MRV 回溯），并断言每关神龛都有可玩数据——改坏数据直接红。
2. **判定层**：胜负按**规则**判（数独=行列宫合法排列，数织=行列线索吻合），不再逐格对答案。
   将来引入多解题，玩家推出的任一合法解都能过，不会"明明解对了却判错"。
3. **兜底层**：数据不可玩时神龛按已解处理（fail-open，只在本次会话生效、不写档不发奖），
   开龛被拒，谜题门自动放行；`frame()` 捕获单帧异常并继续主循环（一次渲染越界不再永久冻死整局）；
   `?level=abc` 等非法参数回落第 1 关。
4. **能力层**：H 键逐格提示，无限次——不会做也能一格一格点过去。
   v7.5 起每格 -1 金币（金币为 0 时免费照给、不扣成负数）：既保留"必可通关"，又不至于一键白送。

### v7.5 可达性护栏（"走得到"与"解得开"是两件事）

v7.4 只证明了谜题数据可解，没证明玩家**走得到**神龛——神龛悬在虚空、卡在实心块后、或高出最大跳跃
高度时，谜题再完美也白搭。`tools/reach.js` 补上这一环：

- **不做弧线估算，直接驱动 `updateWorld` 跑真物理**。节点 = 地面落脚点，每个节点展开一组宏动作
  （等待 / 走 / 跳×跳跃高度×二段跳时机×冲刺时机 / 空中反向 / 风柱内多段变速），落地即新节点，
  A\* 按到目标的距离挑节点。二段跳、冲刺、弹簧、风柱、移动平台、拉杆开关砖、传送门全部走真实代码路径。
- **witness 即证据**：搜到路径后，把帧级按键序列在**全新关卡实例**上原样回放，能再次命中才算 PASS。
  回放失败只报 WARN，不谎报通过。
- 抽象边界：敌人/锯齿/炮台/吊灯摆锤被清空（可击杀或可躲避的周期障碍，不构成几何阻断）；
  尖刺与熔岩保留真实伤害，路径累计扣血 ≥ 5 判为致命；按键以固定 60Hz 注入。
- 当前结果：**26/26**（13 神龛 + 13 终点）全部命中并回放验证，耗时约 17s。

顺带查出并修掉一个真 bug：`engine.js` 的 `solid()` 不认传送带 `(` / `)`，而 `levels.js` 的 STAND 集合认
——L4 把传送带铺在地面行，于是那 8 格画着地板的传送带是**无底洞**，踩上去直接掉出地图；
"逆行传送带"这个机制此前从未真正生效。两处口径统一后传送带既能站立也能推人。

### v7.6 三方口径统一（"看得见的必须能碰，碰得到的必须看得见"）

一个瓦片/实体在引擎里有四套口径：**渲染表**（`renderTiles` 的 `switch`）、**碰撞表**（`solid()`）、
**伤害表**（hazard 判定）、**静态断言集**（`SOLIDISH` / `STAND`）。任一分叉就长出「隐形墙」或
「看得见没反应」。用两个审计脚本（`_audit_tiles.js` / `_audit_ent.js`）把四套表逐格对拍，修掉 8 项：

| 缺陷 | 现象 | 修法 |
|---|---|---|
| `'B'` 木箱不绘制（16 关 80 处） | 实心但全不画 = **一面看不见的墙** | `renderTiles` 补 `case 'B'`，缺素材回落 block+裂纹 |
| 敌人站单向平台 `'='` 掉落 | L6/L14 90 帧掉 80px / 318px | 敌人落地补单向平台（同玩家 `standOn` 口径） |
| 蝙蝠巡逻不查墙 | 31 只里 7 只整只飞进墙内，300 帧嵌墙 543 帧 | 前方探测 + 撞墙钳位掉头；正弦浮动也查 |
| 炮台炮口被木箱堵 | 子弹最大飞行 9px | 开火前 6 格净空检查，被堵不开火（砸箱自动恢复） |
| 魂火自爆判定 30px | 精灵仅 10×10，视觉没碰到就掉血 | 半径 30→16，改「爆心到玩家矩形最近点」 |
| 弹簧触发带高 10px | 脚底偏移 -12~+14 都触发 | 收紧到精灵可视 `[s.y-2, s.y+6]`，用本帧扫掠区间防快落漏判 |

### v16 Boss 招牌独占（"撞来撞去这个技能不要谁都给"）

玩家反馈：三连撞几乎每只 Boss 都会给，撞起来整条通道都占满，「boss 撞来撞去这个技能不要谁都给啊，这个很难躲的」。
v16 把招式按 Boss 划**归属**：每只 4 招招牌，六只共 24 个槽位互不重复；公共层只留两招——
`barrage` 弹幕（每只都有的普攻）与 `nova` 全屏双环（只在 P2 追加）。于是 P1 每只 5 招、P2 6 招，
看招式就能认出对面是谁，而不是「又撞了一次」。`charge` 现在归牛魔王专属；`dive`（跳劈落地甩环）
和 `leap` 是同一套抛物线，等于变相重合，已从所有池子里撤掉（参数保留，随时能再挂回去）。

### v17 装饰交互（"有建模但是没有交互的还有多少"）

玩家拿着 L2 的截图问：石笋长得跟地刺一样，踩上去却什么都没发生——「像这种有建模但没交互的还有多少？」
全面审计 35 种装饰类型后，把 14 种「长着可交互外观」的改成真交互（v17 首轮 12 种 + v17.1 追加齿轮/阀门），
原则一句话：**长得像什么，就表现得像什么**。

| 类型 | 现在的行为 |
|---|---|
| 石笋 / 火焰柱 / 鬼火 / 黑曜石（16 处，L2/L5/L14/L15） | 尖刺、明火——踩上去扣 1 心（吃无敌帧，贴边擦过不扣） |
| 圆石 / 铁桶 / 陶瓮 / 骷髅 / 肋骨 / 熔岩砾石（37 处） | 可打碎——攻击一挥就碎，+1 金币 +1 连击 |
| 齿轮 / 阀门轮盘（6 处，L4/L6，v17.1） | 可打碎——金属机械件，砸下来 +1 金币（你截图里那个轮子就是它） |
| 水晶簇 / 小水晶（10 处） | 可收集——走过就捡，+1 金币（和 '*' 宝石一个待遇） |

v17.1 还修了一个 L6 的**死锁 bug**：门接触判定只认「从左边贴门」——从右侧贴门时扫描范围
永远落不进门所在列，而最终之塔的路线恰好是「甲板（门右）→ 穿门 → 塔顶（门左）」，拿钥匙站在
门前门就是不开。修法是接触范围向四周外扩 1px，两边对称。

配套规则：危险装饰不进 Boss 关、不压出生点/终点/弹簧/神龛/宝箱（出生点站 5 秒不掉血，安全区不是抽签区）；
碎掉/捡掉的复活后不回滚（与碎砖同口径）；草花蘑菇云朵珊瑚等 21 种语义无害的保持纯装饰——
它们不是「没交互」，是「本来就不该有交互」。奖励金币直入口袋、不计入星级分母（与宝箱同口径）。

### v19 第二角色：星语法师（"再构建一个角色，偏向法师、技能主要远程"）

勇者已经能打能跑能盾，再做第二个角色如果只是"换个皮 + 多一颗技能"，等于没做。v19 的设计主轴是
**资源循环**：法师的法力只从战斗里来，技能必须靠持续输出养——远程优势不能白送。

| | 星旅勇者（默认） | 星语法师 |
|---|---|---|
| 生命 | 5 心 | **4 心**（玻璃大炮） |
| 普攻 | J 近战 18×14 判定框 | J 奥术飞弹 8×6、300px/s、射程 255px，±26° 锥内微追踪 |
| 资源 | 无 | 法力 100：自然回 5/s、普攻命中 +8、击杀 +12 |
| U | 星陨术（三流星 AoE） | 冰晶长矛：穿透 3 敌、每敌 3 伤（30 法力，6s CD） |
| I | 星光护盾（3s 吸 2） | 星辉屏障（2.5s 吸 2，25 法力，10s CD） |
| L | 星刃回旋（去回两程） | 追星弹：3 枚 260px 自动追踪，每枚 2 伤（25 法力，6s CD） |
| O | 流星连斩：时停 + 屏内全灭 + 清弹幕 | 陨星风暴：0.35s 吟唱后 6 颗陨星、每颗 3 伤（不耗蓝、不清弹幕） |

平衡三脚架：**射程 255px + 法力门槛 + 少 1 心**。普攻 DPS 约 5.3（勇者 5.7），但并不更肉；
U+L 一轮 55 法力，纯靠自然回蓝要 11 秒，站着丢技能的法师很快就只剩普攻。
法力不足时 U/L/I **不扣蓝、不进 CD、不吞输入**，只给一次红字提示——"按了没反应"比"没蓝"更劝退。

实现上只在一个地方分流：`_engResolveAttack` 首行按 `game.hero` 分流，骑士逻辑逐字未动；
远程弹体走独立的 `game.shots`（不复用敌方 `game.bullets`，否则会被自己的弹打死）；
大招复用唯一的 `game.ult` 状态机，用 `kind:'mage'` 分支；`PHY` 一字未改，`reach` 门禁仍全绿。
换色皮肤（20 套）依然只属于勇者——法师是另一个角色，不是勇者的第 21 套衣服。
