# v20 · 地图二「回响之厅」（L20~L24，五关全 Boss）

> 玩家原话：「现在所有的关卡算是地图1，你应该做一个地图2，但是只需要有 boss，先做五个 boss，
> 每个 boss 都要有自己独特的风格和技能……一定不要和前面的 boss 重复了」
>
> 紧接着的纠正：「**你别嗯抄啊，肯定要有一些自己的想法的**」——所以本作不照搬任何现成游戏的 Boss 设计，
> 下面这套机制是自己长出来的，出处只用来解释「为什么这么想」。
>
> 本文件是**唯一真值**：五只的名字、字段、数值、判定挂点都在这里冻结。
> 可执行版本是同名的 `BAL.boss7~boss11` 与 `tools/_v20_boss_test.js`（44 条断言）。

## 一、地图二与地图一的分水岭：威胁从哪来

地图一六只的威胁**从 Boss 飞向玩家**：弹幕 / 推进墙 / 水雾 / 陨石 / 地刺 / 召唤物。
玩家的动作恒为两件——**躲** 和 **打**。二十六种交互只是这两件事的花样排列，
所以再做第七只、第八只，只要还在这套框架里，就必然重复。

地图二换的是框架本身：

| | 地图一 | 地图二 |
|---|---|---|
| 威胁来源 | Boss 的技能 | **玩家自己的行为** |
| 玩家要学的新动作 | 躲 / 打 | **停手 / 换目标 / 等 / 挑窗口 / 背谱** |
| Boss 的读招点 | 前摇图形 | 玩家自己的状态（伤害量、方位、站位、节奏） |

每只 Boss 只回答一个问题：

| 关卡 | Boss | 主题 | 它在问的问题 | 玩家被迫学会的新动作 |
|---|---|---|---|---|
| L20 | 余烬回响（烬） | ember | 你打得多快？ | **停手** |
| L21 | 双生天秤（秤） | aether | 你一直从哪边打？ | **穿到另一边** |
| L22 | 孵化之间（茧） | husk | 你什么时候打？ | **等它长大** |
| L23 | 无声之喉（喉） | maw | 你用什么打？ | **挑窗口，别喂它** |
| L24 | 终末之钟（钟） | bell | 你现在能打吗？ | **背曲谱** |

五只的招牌招（flare / weight / spawn / inhale / score）**都不产生新弹种**——它们读玩家侧状态再惩罚。
新增的普通招（sear / lash / swap / beam / web / swarm / bite / pendulum / chime / hammer）才有实体，
且逐个避开地图一已用的 26 种交互：没有第二份陨石雨、没有第二个地刺、没有第二种火柱、没有第二个推进墙。

## 三、机制挂点（只有两个）

### 3.1 承伤侧：`_engBossHurt(dmg, isUlt)`

攻击 / 星陨 / 连斩 / 法师弹体**四条支线全部走这里**，所以「这一下算不算数、算多少」的机制只能挂它。
挂在攻击路径上必漏三条。

| Boss | 钩子内容 | 数值口径 |
|---|---|---|
| 烬 | `game.heat += real × perDmg`（`real`=破绽/破防放大后的值） | 1 伤 = 4 热量 |
| 秤 | 按玩家相对 Boss 中心的方位累计 `b.skew`；**真穿身**（位移≥8px）→承伤 ×1.25；同侧到 ±3→失衡：该击承伤 ×0.2、偷回 1.2% 总血、**吞掉破绽态**（stagger/破防窗口清空） | 不跨段 |
| 钟 | 谱上非休止拍 → **完全免伤**（`return false`）；休止拍 → ×1.6 | 见 §3.2 |

**钟为什么免伤而不是减伤**：×0.12 减伤时玩家能看到血条还在动，于是继续埋头砍；
完全免伤才逼他抬头看曲谱。这是全作唯一一只「现在打它没用」的 Boss。

### 3.2 出招侧：曲谱不走轮转

`_engBossPick` 顶部：`if (b.kind === 11) { _engBossScore(b); return; }`。
轮转的「顺延防重复」会让顺序每轮都变，而钟的全部设计前提是**谱固定、可以背**。
曲谱连 P2 连段都不许插进来——`comboQ` 直接写成单招（长度 1 ⇒ recover 不触发连段分支）。

### 3.3 玩家侧新状态

| 字段 | 谁维护 | 清零点 |
|---|---|---|
| `game.heat` / `game.heatT` | `_engM2Heat(dt)`（主循环 ⑨′²，仅 kind7 在场时跑） | 引燃 / 满值自爆 / 换关 |
| `game.mawMeals[]` | `inhaleCast` 吞弹时 push，`roarCast` 吐出时清空 | 换关 |
| `p.webNoJump` | `web` 命中时置 0.08s | 与 `p.mistT` 同处衰减；复活清零 |

**减速不许开第二条通道**：`web` 复用 `p.mistT` / `p.mistSlow`（玩家移速钳制处唯一的乘数），
再开一条并行通道会出现两个乘数相乘的叠乘 bug。

## 四、五种新场地实体（全部走 `game.hazards`）

不新建数组——它们与陨石/地刺/火柱同一生命周期，**跨段清场、Boss 死亡清场、玩家复活清场**三条现成规则都要继承，
独立数组必然漏掉其中一条。

| kind | 字段 | 行为 | 躲法 |
|---|---|---|---|
| `laser` | `x,y,w,h,t,dur,dmg,hitCd,dir,beam?` | 细长矩形，存续 `dur`；`hitCd` 0.5s 防连击 | 离开那条线 / 跳过去 |
| `weight` / `hammer` | `x,y,vy,r,warn,warnT,fall,splash?` | 影子预警 `warn` 秒 → 下落 → 落地圆判定；`hammer` 落地额外溅左右两片横向冲击波 | 离开影子 |
| `crawler` | `x,y,w,h,vx,dmg,life` | 贴地直线爬行，撞墙消失 | 跳 |
| `egg` | `x,y,w,h,t,stage,hp,maxHp,stageT,flashT` | 每 `stageT` 进化一级（0 卵→1 幼虫→2 成虫）；**打碎只升一级，不消失** | 打早=提前放出来；等成虫再打才给能量 |
| `web` | `x,y,w,h,life,slow,noJump,t` | 地面减速区，且禁跳 | 别进去 |

**卵的受击分工**：攻击路径只把 `hp` 扣到 ≤0，**绝不 splice**；收尸/进化统一在 `_engUpdateHazards`。
否则「最后一刀打碎卵」会在攻击里直接消失，玩家永远看不到自己把卵打成了幼虫——那才是最该看到的惩罚反馈。

**落点在前摇结束瞬间锁定**（`landX` / `pendDir`），与 `leap` 同口径：起手后往外走一步就能躲。

## 六、验收

`node tools/_v20_boss_test.js`（44 条，全绿）：

- **T1 去同质化**：五只池逐字对表 + 与地图一六只、彼此之间零交集。
- **T2 烬**：伤害→热量换算、停手加速散热、低热量引燃打不着、热量越高越疼。
- **T3 秤**：同侧连击被偷血、失衡归零、换边承伤 ×1.25。
- **T4 茧**：产卵 3 枚、3s 进化、打碎只升一级、成虫才给能量、网内减速+禁跳。
- **T5 喉**：吸气吞弹回血、反刍吐成弹幕、空嘴白放。
- **T6 钟**：谱两轮一致、非休止完全免伤、休止 ×1.6。
- **T7 清场**：换关后无残留。

实机：`node tools/gate.js engine`24 关全绿（kind 7~11 逐关冒烟）；`tools/_v20_shots.py` 零 pageerror，
输出 `testshots/_v20_select.png`（四章布局）、`_v20_boss7~11.png`（五只本体）、`_v20_fx_*.png`（12 个前摇）、
`_v20_hz.png`（五种实体铺满）。
