# v2.5 美术 richness 规格书：像素不等于素

> 玩家反馈：美术太素。诊断：平涂单色块 + 纯黑描边 + 装饰稀疏 + 背景层数少 + 无环境氛围。
> 目标：达到"精美像素风"（参考：Celeste/星露谷/闪翼双星的界面饱和感）——
> **约束：只改 art.js，gate art 必须保持绿色；不改 ui.js/engine.js/levels.js**。

## 为什么现在"素"（逐条对号）

1. 瓦片 1-2 个色阶平涂，无光影方向、无材质细节；
2. 精灵纯黑描边（像素游戏大忌：廉价感），主体 2 色无渐变无高光；
3. 每主题装饰仅 3-4 种、摆放率 16%；
4. 背景只有 2 层剪影，无中景、无天光渐变细节、无氛围元素；
5. 主题之间差异只靠换色，没有"专属母题"。

## 强化规格（全部在 art.js 内实现）

### A. 瓦片（tiles.*）
- 每种实心瓦片 **≥4 个色阶**：受光（左上）→ 基色 → 阴影（右下）→ 暗缝；色阶边界用
  **棋盘抖动（dithering）** 过渡（每 1px 交替），禁止硬色带。
- 主题材质母题（画进瓦片本身）：
  grass：草帽层=两层绿+草簇+偶发小花/蘑菇帽顶；泥土内嵌小石子与须根；
  cave：岩面苔藓斑块+角落微光晶体（亮青点）；factory：铆钉四角+警示斜纹条+锈斑；
  lava：黑玄武岩+发光裂纹（橙红）；tower：紫砖+符文刻痕+苔点。
- 平台/冰/切换砖/木箱：同规格多色阶+边缘高光 1px+底部投影暗示。

### B. 精灵（SPR.*）
- **彩色描边**取代纯黑：描边色=填充色的加深版（如草绿→深墨绿），主体感立刻立体；
- 主体 **≥3 色阶** + 1px 镜面高光（金属/金币/宝刀）；主角围巾做橙→黄渐变 3 段；
- 金币加扫光帧、宝石做切面折射（亮三角+暗三角）、电锯金属拉丝+高光弧、
  弹簧金属圈高光、炮台加警示灯（红色 1px 点）。

### C. 装饰物（decor.*）
- 每主题 ≥6 种（原 3-4），新增：grass=高草丛+圆石；cave=石笋+发光蠕虫；
  sky=热气球+风车草；factory=阀门+吊灯；lava=骸骨+小火焰柱；tower=旗帜+烛台；
- 摆放密度 16%→**28%**（摆放逻辑在 engine——不改，只把素材备齐：多型供随机）；
- 火把/晶体等做成 **2 帧闪烁数组**（ui 已支持数组帧动画，无需改 ui）。

### D. 背景（bg）
- 每主题 **3 层**：far（天光/星月/远景母题）+ **mid（新增中景：树线/钟乳石林/云带/
  管道群/熔岩柱/塔群剪影）** + near（现有）；层间用透明度/明度区分空气感；
- 天空渐变从 2 色阶升为 **3-4 色阶**（地平线附近加暖/冷色带）；
- far 层加入静态"氛围点"：grass=飘尘、cave=萤光点、sky=远处飞鸟形、factory=烟囱烟、
  lava=上升火星形、tower=大小星+月晕（静态绘制，动画帧支持留给 ui v3）。

### E. 自查与验收
1. `node tools/gate.js art` 退出码 0（导出符号一个不能少）；
2. 用 playwright 对 6 关各截 1 图（file:///...index.html?level=N，浏览器全屏 1152x680），
   用 analyze_image MCP 工具自评每图：色阶数/装饰密度/主题辨识度，"素"的项继续迭代
   （最多 2 轮）；
3. 禁止外部图片与网络素材；字符网格/程序化绘制均可，总量控制在 art.js ≤ 80KB。

## 不做（越界即失败）
不改 ui.js/engine.js/levels.js；不新增导出符号；不动门禁。
（背景逐帧动画、环境粒子、HUD 美化属于 ui 层，已列入 v3 界面队工单范围。）
