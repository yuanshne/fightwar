# v13 Boss 交互类型扩展 II（冻结接口）

> 本文件是 v13 的唯一接口真值。engine / ui / art / test 四路并行开发，**不得自行改字段名**。
> 违反 R4（Boss 差异只能来自 `_engBossTable` 命中的参数表，禁止第二份状态机 switch）的实现直接打回。

## 一、设计原则（沿用 v12 结论）

v10 已有 8~10 招，但**应对动作只有一种**（看预警走开）= 无聊。
v12 加了 7 种类型（多段连撞 / 召唤回血 / 蓄力结界 / 抓取 / 劈地波 / 火柱 / 核心护盾），
v13 再加 5 种，**每一种都惩罚一种不同的坏习惯**：

| # | 类型 | 惩罚的坏习惯 | 正确动作 | 归属 |
|---|---|---|---|---|
| 8 | `parry` 反伤架势 | 无脑连打 | 收手 1.8s，或用大招破招 | boss5 圣裁者 |
| 9 | `mirror` 真假身 | 乱打目标 | 看清再打，打错爆炸 | boss3 判官 |
| 10 | `push` 推进墙 | 站桩输出 | 朝 Boss 方向持续跑 | boss4 冥古龙 |
| 11 | `bomb` 弹跳炸弹 | 见落点就躲死 | 记住它会弹两下，落点会变 | boss6 牛魔王 |
| 12 | `mist` 水雾区 | 原地不动 | 立刻换位置（跳不出去，雾到顶） | boss2 蛟龙 |

## 二、BAL 参数（逐字实现）

```js
// boss5（圣裁者）
parry:  { dur: 1.8, reflect: 1, breakT: 2.4 }
// boss3（判官）
mirror: { n: 3, life: 5.0, hp: 1, popDmg: 1, swapOff: 96 }
// boss4（冥古龙）
push:   { w: 24, h: 64, v: 88, dmg: 2, warn: 0.9 }
// boss6（牛魔王）
bomb:   { n: 3, gap: 0.32, vy: -300, vx: 110, grav: 900, bounce: 2, damp: 0.55, fuse: 0.9, r: 30, dmg: 1 }
// boss2（蛟龙）
mist:   { n: 3, w: 56, h: 96, life: 4.0, tick: 0.5, dmg: 1, off: [-80, 0, 80] }
```

`windup` 表各补一键：`parry: 0.55`（boss5）、`mirror: 0.60`（boss3）、`push: 0.75`（boss4）、
`bomb: 0.55`（boss6）、`mist: 0.60`（boss2）。
`recover` 表同样补同名键（值取该 Boss 表内中位数，0.5~0.6）。

选招池：
- `boss2.poolNear/poolFar` 追加 `'mist'`
- `boss3.poolNear` 追加 `'mirror'`
- `boss4.poolNear` 追加 `'push'`
- `boss5.poolNear` 追加 `'parry'`
- `boss6.poolNear` 追加 `'bomb'`

## 三、hazard 契约

新增 4 个 kind（`parry` 不是 hazard，见 §四）。

### `mirror`（真假身）
```js
{ kind:'mirror', x, y, w, h,          // x,y = 左上角（与本体同尺寸）
  t:0, life, hp, flashT:0,            // hp 受击后减；flashT 闪白
  real:false }                        // ⚠️ UI 绝对禁止读取 real，渲染必须完全一致
```
- 生成时把 **Boss 本体的 x 移到其中一具幻影的位置**，并 `b.hidden = true`（复用 blink 隐身免伤机制）。
- 击破判定（在 `_engResolveAttack` / 星陨 / 连斩三处，与 `core` 同一入口）：
  - `real === true` → `b.hidden=false`，`b.x` 保持该幻影位置，进 `stagger`（`staggerDur = T.stagger*1.5`），浮字「真身!」
  - `real === false` → 爆炸：`_engHurtPlayer(e.x)`（1 心）+ 粒子 + `sfx 'boom'`，浮字「假的!」
- `t >= life` → 全部清除并 `b.hidden = false`（超时保底：不能让 Boss 永久隐身）。

### `pushwall`（推进墙）
```js
{ kind:'pushwall', x, y, w, h, v, dir:1|-1, warnT, dmg, hitT:0 }
```
- 生成：从玩家**背向 Boss 的一侧**进场 —— `dir = (玩家在 Boss 左边 ? 1 : -1)` 表示墙的推进方向（朝 Boss）。
  初始 `x` 放在场地该侧的边缘外侧 32px。
- `warnT > 0`：只画预警（UI 按 `warnT` 画推进方向的虚线），不移动不伤害。
- 移动：`x += dir * v * dt`，`hitT` 每帧递减。
- 命中：AABB 与玩家相交且 `hitT <= 0` → `_engHurtPlayer(e.x)`，`hitT = 0.8`（防连帧），并把玩家朝 `dir` 方向推 `vx = dir*220, vy = -180`。
- 出场：`x` 越过场地另一端 → 自删。

### `bomb`（弹跳炸弹）
```js
{ kind:'bomb', x, y, vx, vy, r, t:0, fuse, bounceN, dmg, armed:false }
```
- 生成：从 Boss 中心偏上抛出，`vx = ±110`（左右交替），`vy = -300`。
- 物理：`vy += grav*dt; x += vx*dt; y += vy*dt;`
- 落地（脚底触到 solid）：
  - `bounceN > 0` → `vy = -vy*damp; bounceN--;`，落地粒子 + `sfx 'shot'`
  - `bounceN <= 0` → `armed = true`（开始 `t` 计时）
- `armed && t >= fuse` → 爆炸：`_engHurtPlayer(e.x)` 若 `|dx| < r && |dy| < r`，粒子 + `sfx 'boom'`，`dead = true`。
- 空中直接砸到玩家 → 也爆（同 meteor 口径）。

### `mist`（水雾区）
```js
{ kind:'mist', x, y, w, h, t:0, life, tickT:0, dmg }
```
- `y` 是地面上沿（`h` 向上长）。
- 每 `tickT <= 0` 且玩家在框内 → `_engHurtPlayer(e.x)`，`tickT = tick`。
- `t >= life` → 自删。
- **不阻挡移动、不阻挡攻击**，纯持续伤害区。

## 四、`parry`（反伤架势，非 hazard）

Boss 状态 `parryCast`：
- 进入：`windup('parry')` 结束 → `state='parryCast'`，`b.parryOn = true`，`b.t = 0`。
- 期间 `_engBossHurt` 分支（**必须放在 coreOn 之后、正常扣血之前**）：
  - `b.parryOn` 且 `!isUlt` → **不扣血**，`_engHurtPlayer(b.x)` 反弹 1 心给玩家，
    `b.flashT = 0.08`，`sfx 'clank'`，浮字「反弹」，返回 `false`。
  - `b.parryOn` 且 `isUlt` → **破招**：`b.parryOn=false; b.state='stagger'; b.staggerDur = T.stagger*1.6; b.t=0;`
    `b.breakT = T.parry.breakT;` 浮字「破招!」，`sfx 'bossbreak'`，返回 `true`（这一击照常扣血）。
- 退出：`b.t >= dur` → `b.parryOn = false`，`recover`。
- `_engBossHurt(dmg, isUlt)` **签名扩展**：四个调用点逐一处理，
  **O（流星连斩起手 + 刀光命中）与 U（星陨）都算大招，传 `true`**；普攻（`_engResolveAttack`）传 `false`。
  理由：只让 U 能破的话，O 起手打在架势上会自伤——O 是清屏技、误按概率远高于 U，玩家会直接判定成 bug。

## 五、玩法层：破防窗口 `breakT`

- Boss 新字段 `breakT`（秒，0=未破防）。
- 任何「破招」事件统一置 `b.breakT = 2.0`：用大招破 `parry`、打碎全部 `core`、打断 `quell`。
- `_engBossHurt` 倍率：`b.breakT > 0 ? 2.0 : (b.state === 'stagger' ? 1.5 : 1)`。
- 每帧递减（在 Boss 主更新里，任意状态都减）。
- UI：`breakT > 0` 时在 Boss 头顶画「破防」+ 剩余条，且血条描边变金色。

## 六、UI 契约

新增渲染函数，全部带守卫（字段缺失/未知 kind 跳过，**绝不白板、绝不抛错**）：

| kind | 渲染 |
|---|---|
| `mirror` | 与本体同剪影，叠 55% 透明 + 紫色描边抖动；**不看 `real`** |
| `pushwall` | 高墙 + 推进方向斜纹滚动 + 顶部尖刺；`warnT>0` 时只画半透明虚线轮廓 |
| `bomb` | 引信闪红（`armed` 后频率加快）+ 落地阴影 + 爆炸前 0.2s 白闪 |
| `mist` | 竖向半透明青色渐变柱 + 上升气泡，顶边柔化 |

`renderBossWindupFx` 新增 5 个 case，前摇面板：
- parry → 金色盾形 + 「反」字
- mirror → 三个紫色残影 + 「?」字
- push → 箭头 + 「推」字
- bomb → 抛物线虚线 + 「弹」字
- mist → 青色气团 + 「雾」字

`renderBossTags` 新增：`parryOn` 画「反」红标；`breakT>0` 画金色「破防」进度条。

## 八、硬约束（违反即打回）

1. `hpTotal` 是总血唯一真值，`hp` 是派生；破防倍率只改 `_engBossHurt` 内部的 `real`，不许写 `b.hp`。
2. 所有新 hazard 必须在**跨段 / 真死 / 接力 / respawn / 换关**五处随 `game.hazards = []` 一起被清掉 —— 这些点位已是整数组替换，**不要新增单点清理**。
3. 每个新 windup/cast 参数必须 `T.xxx || BAL.<参考表>.xxx` 兜底（v12 踩过：boss6 缺参数对象直接抛异常）。
4. 伤害统一走 `_engHurtPlayer`（护盾/无敌帧照常生效），不许直接改 `p.hp`。
5. UI 只读字段，一个都不改。
6. 新 hazard 若涉及「Boss 免伤」，必须提供**超时兜底**（mirror 超时、pushwall 出场、bomb 自爆），不允许出现永久免伤。
