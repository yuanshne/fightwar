| 阶段转换 | — | 首次 ≤30 触发一次 `enrage`：吼叫 72 帧、变色（调色板换装）、清自身前摇 |
| J 攻击承伤 | 1/次 | 1/次 |
| 星陨承伤 | 1/星 ×3 星 | 同左 |
| 流星连斩承伤 | 5 | 5 |
| idle 时长 | 36 帧（0.6s） | 27 帧（0.45s） |
| 前摇时长 | 见 §3 表 | 表值 ×0.85 |
| 缓步漂移 | 20 px/s 朝玩家（\|dx\|>140px 时） | 25 px/s |
| 冲刺速度 | 230 px/s | 290 px/s |
| 跳跃 | 蓄 30 帧 → 抛物线（dx 钳制 ±300px，滞空 ≈0.9s，g=1500，vy 上限 520） | 同左 |
| 接触伤害 | 1 HP（吃玩家 1.0s 无敌帧）+ 击退 | 同左 |

| 冲击波伤害 | 1 HP/道 | 同左 |

**击杀预算推导**：纯 J：60 次 × 0.35s CD ≈ 21s 理论 + 走位/躲避 ≈ 45~75s 实战；

**召唤物**：标准史莱姆（复用 `W` 实体结构，engine.js:121-123），可踩/可斩，
死亡 30% 掉回复心。场上存活召唤物 ≥2 时 `summon` 改发 `barrage`。

### 选招规则 `_engBossPick`（确定性轮转，不用随机）

```
dx = 玩家中心x − Boss中心x; adx = |dx|
P1 近距池(adx≤200px):  [charge, leap, summon, charge]
P1 远距池(adx>200px):  [barrage, charge, leap, barrage]
P2 两池各追加一个 'nova'
若存活召唤物≥2 → 从池中剔除 summon；再剔除 lastPattern（剔空则取 [barrage]）
choice = pool[b.pickN++ % pool.length]; b.lastPattern = choice
```

## 4. 角色技能（3 个）与键位

| 键位 | 技能 | CD | 施法 | 效果 | 数值 |
|---|---|---|---|---|---|
| **U** | 星陨术 | 8s | `castT=0.25s` 金色攻击姿 | 头顶召 3 颗流星，间隔 15 帧，落速 300 px/s，落点=目标 x±{-20,0,+20} | 单星伤 1（Boss 或普通敌），落点 AoE 24×24 可碎 `B` 木箱；每星命中震屏 3 |
| **I** | 星光护盾 | 12s | 即时 | `p.shieldT=3.0s` 金色泡泡 | 免疫一切 **HP 伤害**（接触/弹幕/冲击波，含击退）；**不挡即死物**（尖刺/熔岩/电锯/坠落/挤压） |
| **O** | 流星连斩 | 20s + `game.combo≥8` | 即时 | 全屏斩击：`hitStop=0.12s`、`game.flashT=0.15` 白屏、震屏 8 | Boss 伤 5；屏内普通敌全灭（照常滚掉落）；`game.bullets` 全清；**消耗连击：combo=0, comboT=0** |

**目标选择（星陨）**：`game.boss` 存活且非 dormant/dying → Boss 中心；
否则 200px 内最近敌人 → 该敌人；否则玩家面朝方向 44px 处（L1-L6 也能用，砸 B 箱）。

**连斩充能口径（对 brief 的一处修正，含推导）**：brief 要求「combo≥8 才可放」。
v2 连击窗口 2s（engine.js:81），攻击 CD 0.35s → 窗口内最多约 5 次命中，**combo 8 不可达**。
修正：**攻击/星陨命中 Boss 时连击 +2**（`_engAddCombo()` 调两次，大体型反馈），
4 次命中（t≈1.05s）即 combo=8，连斩在窗口内可放——仍完全复用 `game.combo/game.comboT`，
不新增能量槽。若实测节奏不佳，回退方案见 §10。

**技能全关卡可用**（HP 系统全局生效的配套）；UI 技能栏常显（L1-L6 同样显示）。

## 5. 玩家 HP / 无敌帧 / 掉落规则（全局生效）

| 项 | 规则 |
|---|---|
| 上限 | `p.hp = 5`（HUD 左上 5 颗心，工单术语「心形HP」；美术画 heartFull/heartEmpty 8×8） |
| 受击 | `-1 HP` + 击退（离伤害源方向 `vx=±160, vy=-140`，中断冲刺/攻击）+ **无敌 60 帧（1.0s）** 闪烁 |
| 受伤无敌内 | 再次受击来源全部免疫（含击退） |
| 护盾 | `shieldT>0` 时等同无敌（对 HP 伤害） |
| HP=0 | 走 v2 死亡序列 `killPlayer()`（0.9s 冻结 → respawn） |
| respawn | HP 回 5、`invT=1.5s` 出生保护、`shieldT=0`、技能 CD **保留计时**；Boss 战：Boss **HP/阶段保留**，状态回 `idle`（t=0、速度清零），`bullets/waves/meteors` 清空，召唤物由既有敌人重置逻辑处理（engine.js:287-291） |
| **即死（不走 HP，护盾不挡）** | 尖刺 `^v`、熔岩 `~`、电锯、移动平台挤压、坠落出界——保留平台关张力 |
| **HP 伤害（-1）** | 敌人接触（非踩踏）、大炮/Boss 弹幕、冲击波、Boss 身体接触 |

**掉落规则**：踩踏或斩击击杀敌人 → `Math.random()<0.30` 掉 1 颗回复心
（`game.drops`，8×8，上抛 vy=-120 受重力，落地停留，寿命 6s，最后 2s 闪烁）。
拾取 `hp=min(5, hp+1)`，音效 `'heart'`。Boss 本体不掉心（召唤物即补给线）。

## 10. 风险与调参杠杆

1. **连斩门槛**：命中 Boss 连击 +2 是修正口径（§4 推导）。若体验差 → 回退为独立能量槽
   `game.ultCharge`（命中+1 不衰减，≥8 可放）——接口已预留（`skills.o` 结构不变）。
2. **HP 全局化改变 L1-L6 难度**：敌触/炮弹从即死变 -1（brief 指示「全局生效」）。
   尖刺/熔岩/坠落仍即死，平台关张力保留。若过简 → 调 `invT` 1.0→0.7s。
3. **冲刺无敌帧**：v2 冲刺无 i-frames（保持）。若 Boss 冲刺碾压体验差 →
   开关 `p.dashT>0 时免疫 HP 伤害`（engine 单行，默认关）。
4. **Boss 保留 HP 复活**（战争磨血）：靠 5 心+检查点平衡；过易 → 改「玩家死亡 Boss 回
   `max(当前HP, 31)`」（锁 P2 起点）。
5. **弹幕 vy 扩展**：需回归验证大炮弹轨迹不变（`vy undefined → +0`）。
6. **art.js 体量**：Boss 身体用行跨公式程序化（非全字面网格），部件小网格字面——控制增量 ≤18KB（v2.5 预算 80KB）。
7. **gate 桩 THEMES 无 'boss'**：engine 对 `THEMES[theme]||{}` 已有兜底（engine.js:91）；
   ui 工单仍会补桩，双保险。
8. **选关 7 格布局**：3×3 网格重排（ui 硬编码 6 处全数列出在 ui 工单），星级 `/21`。
