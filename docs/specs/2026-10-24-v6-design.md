## 2. 技能 4·星刃回旋（L 键）完整规格（第一波：引擎=手感队，素材=特效队，渲染/按键=界面队）

### 2.1 总则

- 键位 **L**（KEYMAP.skillL:['KeyL']，未占用）；CD **6s**（`game.skills.l`，受披风 CD-% 缩减：实际 CD = 6×(1−eqCd)，平衡表 §P）。
- 施放条件：`skills.l<=0 && !p.dead && p.dashT<=0.05 段外`（冲刺蓄力段不可掷，爆发/滑行段可掷——宽口径：`p.dashT<=0 || (0.28-p.dashT)>=0.05`）。
- 施放瞬间：`p.castT=0.2`（复用施法姿态 heroAttackGold 渲染 ui.js:797-801）；sfx `'blade'`；不做 hit-stop。

## 3. 四类敌人技能（第一波：引擎=手感队，前摇 FX/素材=特效队，渲染=界面队）

**统一结构**：敌实体加 `e.ai = _engMkAI(type)`（slime/bat/knight 现有 spawn 处 engine.js:202/206/239 与 mage 新增一并给）；`_engMkAI` 返回 `{st:'idle', t:0, cd:初始, tx:0, ty:0}`。规则：

1. AI 推进放敌人循环内（engine.js:1302-1362），死亡态/`hitStop`/`ult`/`bagActive` 由 updateWorld 结构自然冻结。
2. **前摇期间被打断**：不打断（前摇=硬直窗口，玩家可以用攻击/踩踏反制——技能的可读性即反制窗口）。
3. **respawn 复位**：`respawn()` 敌人复位循环（engine.js:446-450）内追加 `e.ai = _engMkAI(e.type)`。
4. 触发全部用距离条件，**无随机**（确定性，门禁空转零触发：空转时玩家在出生点，距最近敌 > 触发半径或 cd 未到）。冷却初值带相位错开：`cd0 = 基础 + ((x*7+y*13)%10)/20`（确定性相位，0~0.5s 错开）。

- 碎片键语义：`slot+r` 稀有度碎片只能升**同槽同稀有度**物品（"秘银武器碎片升秘银武器"）。

### 7.5 外观部件层方案（**已对现有精灵姿势系核验可行**，冻结如下）

**核验结论（依据本轮代码核对）**：
1. 全部主角姿势为 16×16 字符网格（art.js:200-421：idle1/idle2/run[6]/jump/fall/attack/dash/squash + dashWind 435-440），`_makeSprite` 出同尺寸 canvas——**部件层用同规格 16×16 覆盖网格即可全姿势兼容**；
2. 头部在 idle/run/jump/fall/squash 家族位于同列（cols 2..13），attack/dash/dashWind 家族整体 **+1 列**（art.js:371/388 对比 200）——部件锚点仅需两档；
3. `heroAttackGold`（art.js:1053,1371）已确立"同网格+调色板变体"先例；`flipCache/whiteOf`（ui.js:701-712）以 canvas 为键——**合成图天然复用翻转/白闪缓存**；
4. 渲染统一走 `drawImage(img, p.x-3, p.y-2)` 与 `_heroXform`（ui.js:808-823）——**合成后的单张 canvas 零改动接入**（旋转/squash/空翻随动）。

**方案（部件覆盖层 + 合成缓存，非全帧重画）**：

```js
// art.js（外观队）新增素材键（右向基准 16×16，调色板自由）：
SPR.look = {
  weapon: [c1, c2, c3],   // 档1 木纹短剑 / 档2 秘银长剑 / 档3 星辉巨剑（手执式：斜持于身侧，见锚点）
  hat:    [c1, c2, c3],   // 档1 布帽 / 档2 秘银头冠 / 档3 神话金冠（罩头顶 rows0..4）
  cape:   [c1, c2, c3]    // 档1 破布披 / 档2 秘银披 / 档3 星辉披风（背部 cols0..5, rows6..14，画在底层）
};
// ui.js（背包队）合成器：heroPoseImg 返回处包一层 heroLook(img, fam)：
//   fam: 'idle'(idle/run/jump/fall/squash) 或 'atk'(attack/dash/dashWind/cast)
const _lookCache = new Map();      // key=img → {R:合成canvas, L:flipSprite(R)}
function heroLook(img, fam) {
  const eq = lookEq();             // {weapon:-1..2, hat:-1..2, cape:-1..2}（档位，空=-1）
  if (eq.weapon < 0 && eq.hat < 0 && eq.cape < 0) return img;   // 无装备零开销直通
  let e = _lookCache.get(img);
  if (!e) { const c = _makeCanvasUi(16, 16); const g = c.getContext('2d');
    const dx = fam === 'atk' ? 1 : 0;                             // 攻/冲家族 +1 列（核验#2）
    if (eq.cape >= 0)   g.drawImage(SPR.look.cape[eq.cape], 0, 0);       // 披风=底层
    g.drawImage(img, 0, 0);
    if (eq.weapon >= 0) g.drawImage(SPR.look.weapon[eq.weapon], dx, 0);  // 武器=手侧覆盖
    if (eq.hat >= 0)    g.drawImage(SPR.look.hat[eq.hat], dx, 0);        // 头饰=头顶覆盖
    e = { R: c, L: flipSprite(c) }; _lookCache.set(img, e); }
  return game.player && game.player.face < 0 ? e.L : e.R;
}
function _lookDirty() { _lookCache.clear(); }   // 穿/脱/升阶时调用
```

- 适配点（背包队改 3 处）：`heroPoseImg`（ui.js:778-803）返回前包 `heroLook(img, fam)`（fam 由其自身 pose 分支给出：attack/dash/dashWind/castT→'atk'，其余→'idle'）；`updateGhosts`（ui.js:858-866）与 `renderPlayer` 死亡分支（ui.js:829-836）自动随动（都经 heroPoseImg/heroFall——死亡分支直接调 `heroLook(SPR.heroFall,'idle')`）。
- 静态角度武器说明：attack 姿态武器不转向（斜持），挥击表现由 slashArc 弧光承担（判定框与视觉武器无关，engine.js:782）——**记录为已接受的表现限制**，不追帧动画。
- 部件网格设计约束（外观队）：hat 只准占 rows0..4、cols4..11（不遮脸 rows5..8）；weapon 只准占 cols10..15、rows7..15（不遮头）；cape 只准占 cols0..6、rows5..15（避开前身）；透明=网格 `'.'`。
- 预算：9 张 16×16 网格 + 3 张 12×12 图标 ≈ 每张 16 行字符串，增量 <8KB（art.js 基线 124,937B）。
