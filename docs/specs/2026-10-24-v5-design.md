## §1 手感参数总表（第一波·手感队 engine.js）

物理基线沿用 PHY（engine.js:89，键名不得变）：grav 1500 / maxFall 360 / acc 1400 /
fric 1800 / maxRun 120 / jumpV 330 / springV 520 / coyote 0.12 / buffer 0.18。
推导值（供关卡校验用，施工不必重算）：单跳高 h=v²/2g=36.3px≈2.27 瓦；弹簧 90.1px≈5.63 瓦；

### 1.1 二段跳（核心新增）

### 1.4 跑步 / 转身 / 冲刺

- 脚步尘土：地面 `|vx|>60` 且非冲刺，每 0.18s 1 粒（`p.stepT`），位置脚跟偏后 4px。
- 跑动前倾：ui 渲染层绕脚底旋转 `face*2°*min(1,|vx|/maxRun)`（仅 run 态）。
- 转身 squash：face 翻转瞬间 `|vx|>80` → `p.turnT=0.12`，ui 横向 scale 0.72→1 回弹。
- 冲刺三段（总时长 `p.dashT=0.28`，CD 0.8 不变，方向取输入或面向）：
  - 蓄力 0~0.05s：`vx=dashDir*60`，渲染后仰帧 heroDashWind（特效队供）；
  - 爆发 0.05~0.23s：`vx=dashDir*260`，重力减半（沿用），每 0.03s 推 1 枚风粒子（fx 层，青白细长）；
  - 滑行 0.23~0.28s：`vx` 由 260 线性回落到 maxRun（缓冲，不再"匀速滑块急停"）。

## §5 原神风像素化风格指南（第二波·风格队 art.js + 封面队 ui.js）

### 5.1 四条北极星（brief 原文转译，所有美术决策对齐）
1. 高饱和明亮幻想色：晴空蓝 #4a9fe8 系、翡翠绿、落日橙金；**暗部不脏**（提蓝紫 #463a72 而不是压黑）。
2. cel-shading 三阶硬边：亮/固有色/影干净分块；**大幅删减棋盘抖动**（抖动只保留在远景空气感）。
3. 发光元素：关键物件 1~2px 亮边光晕；粒子走"流光"（细长拖尾）而非方点。
4. UI 原神化：半透明深蓝底 + 金色细描边 + 圆角切角（HUD/菜单/谜题面板统一）。

### 5.2 三阶 cel-shading 硬规则（瓦片与精灵通用）
- 每个受光体恰好三阶：**亮面（受光方向=左上）→ 固有色 → 影面（右下）**，外加 1px 暗缝线（描边感）。
- 瓦片 `_paintBlock` 新版（伪代码，风格队照抄）：
