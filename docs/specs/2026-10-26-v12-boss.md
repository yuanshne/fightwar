# v12 Boss 交互层 + 第 19 关（2026-10-26）

> 病根：现有 8~10 招的应对动作全是「看到预警 → 走开」，类型单薄，打两遍就能背板。
> 造梦西游的做法是**每招要求不同的正确动作**。v12 加的是"动作类型"，不是更多红圈。
> 同时新增第 19 关 Boss「烈焰·牛魔王」（kind 6）——蛮力型，把新类型集中展示。

## 〇、七种交互类型（全表）

| # | 名称 | 类型 | 玩家要做的动作 |
|---|---|---|---|
| 1 | `charge` 多段连撞（撞墙反弹变向） | 改造 | 不能在墙边躲，往场地中间绕 |
| 2 | `summon` 召唤物回血 | 改造 | 先清小怪（不清 = Boss 回血） |
| 3 | `quell` 蓄力全屏 AOE（结界 + 可打断） | 新招 | 打断（激进）或站进结界圈（稳妥） |
| 4 | `grab` 抓取摔投 | 新招 | 不能站 Boss 正前方 46px 内 |
| 5 | `quake` 劈地窄高直线波 | 新招 | 跳（26px 高，单跳 53px 可过） |
| 6 | `pillar` 火柱（红圈 → 升柱 → 持续危险区） | 新招 | 离圈，并绕开已升起的柱子 |
| 7 | `core` 核心护盾（Boss 无敌，打核心破盾） | 新招 | 转火打核心，不是继续打 Boss |

## 一、engine ↔ ui 冻结接口（两边都按此实现，**不许改名**）

### 1. charge 多段连撞
- 参数：`T.charge.hits`（总段数，缺省 1 = 旧行为）
- 运行字段：`b.chargeN`（已撞墙段数，0 起；进 `windup(charge)` 时归零）
- `chargeRun` 撞墙（`_engBossPhysX` 返回 true）：
  - `b.chargeN + 1 < hits` → `b.chargeN++`、`b.chargeDir *= -1`、`b.chargeFrom = b.x`、`b.t = 0`、
    震屏 5、`_engFx` 环、sfx `'clank'`，**状态不变**
  - 否则 → `stagger`，`b.staggerDur = T.stagger * 0.7`，清 `comboQ/comboN`
- `maxT`/`maxX` 未撞墙 → 仍进 `recover`（旧行为）
- UI 读：`b.state==='chargeRun' && b.chargeN>0` → 头顶「撞 N/M」

### 2. summon 回血
- 参数：`T.summon.leech`（每只存活召唤物每秒回总血百分比，缺省 0）、`T.summon.leechCap`（单次累计上限%，缺省 6）
- `_engBossSummon` 生成的小怪带 `leech: true`
- 每帧：`n = 存活且 leech 的敌数`；`segCeil = (3 - b.bandBreak) * b.bandMax`（**不许跨段**）；
  `b.hpTotal = min(segCeil, b.hpTotal + b.maxHp*leech/100*n*dt)`；`b.hp = _engSegHp(b)`；
  `b.leechOn` 0..1（有 n 向 1 收敛 / 无 n 向 0 衰减，速率 4/s）
- UI 读：`b.leechOn > 0` → 血条绿色流动高光 + Boss 身上绿光

### 3. quell 蓄力全屏
- 参数：`T.quell = { dur: 2.2, warn: 0.9, r: 22, n: 2, breakDmg: 12, dmg: 2 }`
- `windup.quell = warn`，`recover.quell` 必填
- `quellCast` 进入时（`b.fireN===0`）：`b.quellDmg=0`、`b.quellDur=T.quell.dur`，生成 `n` 个
  `game.hazards.push({ kind:'ward', x, y, r, t:0, life: dur })`，x 取**玩家左右各 120px**
  （实机修正：原「场地 25%/75% 列」距 Boss 576px，相机跟玩家 → 全在镜头外），`y = _engGroundY(x, p.y)`
- 承伤累加：`_engBossHurt` 内 `b.quellDmg += real`（**只在 quellCast**）
- 打断：`b.quellDmg >= breakDmg` → 清所有 ward；`b.state='stagger'`、`staggerDur=1.2`、
  `_engFloat('打断!','#f8d048',1)`、sfx `'clank'`、震屏 8
- 完成：`b.quellFlash = 0.4`；玩家不在任何 ward 圆内（圆心距 > r）→ `_engHurtPlayer(cx, dmg)`；
  清 ward、震屏 10、sfx `'boom'`、进 `recover`
- UI 读：`quellCast` → 头顶蓄力条 `clamp(b.quellDmg/breakDmg)`（满变白闪）；
  hazard `ward` → 金色光柱 + 底圈（r）；`b.quellFlash>0` → 全屏 `rgba(248,80,48,0.35)`

### 4. grab 抓取摔投
- 参数：`T.grab = { reach: 46, dmg: 2 }`，`windup.grab=0.75`，`recover.grab` 必填
- `grabCast` 首帧判定：`b.face>0 ? {x:b.x+b.w,y:b.y,w:reach,h:b.h} : {x:b.x-reach,...}`
- 命中 → `_engHurtPlayer(bcx, dmg)`；玩家被拉近 10px、抛飞 `vx=-face*220, vy=-240`；
  `game.hitStop=0.18`；sfx `'bosshit'`
- `b.t>=0.35` → `recover`（命中与否都走）
- UI 读：`windup && b.next==='grab'` → 面向侧红爪扇形 + 半透明范围框（reach×h），随前摇加亮

### 5. quake 劈地窄高波
- 参数：`T.quake = { w:14, h:26, v:200, life:0.9, n:2, gap:0.35 }`，`windup.quake=0.6`，`recover.quake`
- `quakeCast`：`want=floor(b.t/gap)`，每段推 `game.waves.push({x:刃口,y:b.y+b.h-h,w,h,vx:b.face*v,life,tall:true})`
- UI 读：`wave.tall===true` → 锯齿地裂（高 26），不是普通贴地波

### 6. pillar 火柱
- 参数：`T.pillar = { n:3, warn:0.9, w:14, h:40, life:2.5, gap:0.25, dmg:1 }`，`windup.pillar`，`recover.pillar`
- `pillarCast`：每 `gap` 秒起一根，x = 玩家「当时」位置 ± 交错（`i%3-1` 格），
  `game.hazards.push({ kind:'pillar', x, y:gy, w, h:0, mh:h, warnT:warn, t:0, life })`
  - `gy = _engGroundY(x, p.y)`（柱底=地面）
- 生命周期（`_engUpdateHazards`）：`warnT>0` 只画圈；归零后 `h` 以 160px/s 长到 `mh`，
  之后持续 `life` 秒，`h>=12` 起判伤害（矩形 `{x-w/2, y-h, w, h}`）；到期消失
- UI 读：`warnT>0` → 地面红圈 + 倒计时收缩；`h>0` → 橙红火柱（w×h）

### 7. core 核心护盾
- 参数：`T.core = { n:2, hp:3, life:10, r:9 }`，`windup.core=0.7`，`recover.core` 必填
- `coreCast` 进入（`b.fireN===0`）：
  - `b.coreOn = true`；生成 `n` 个 `game.hazards.push({ kind:'core', x, y, w:18, h:18, r, hp, maxHp:hp, t:0, life, flashT:0 })`
    - x 取 **Boss 两侧 ±150px**（实机修正：原 20%/80% 列同样在镜头外），y 取 `b.y + 20`（悬空，跳起攻击够得着）
  - sfx `'shield'`、震屏 4
- 无敌：`_engBossHurt` 在 `b.coreOn` 时**返回 false 且不掉血**（可闪白 + sfx `'clank'`）
- 核心受击：扩展现有「分身可被普攻打掉」循环（`hz.kind==='clone'` 同构）→ `hz.hp--`、`hz.flashT=0.12`；
  归零 → 消失 + 粒子；`O` 连斩/`U` 星陨对 core 也可扣 1
- 全破 → `b.coreOn=false`、清 core、`b.state='stagger'`、`staggerDur=2.0`、`_engFloat('破盾!','#f8d048',1)`、震屏 10
- 超时（`life` 到）→ `b.coreOn=false`、清 core、回 `recover`（不破盾）

## 四、硬约束（违反即打回）

1. **每招可躲且能脚本断言**：`grab` 背后 60px 不中；`quake` 起跳不中；`quell` 站 ward 圈心不掉血；
   `quell` 打断后转 stagger 且 ward 清空；`core` 期间 Boss 免伤、破盾后转 stagger。
2. **伤害上限 2**：`grab`/`quell` 为 2（长前摇 + 专属预警），其余 1。禁秒杀。
3. 前摇 ≥0.5s，且 UI 有**专属**预警图形（不只切姿态）。
4. **回血不跨段**：`hpTotal` 封顶 `(3-bandBreak)*bandMax`。
5. 新增 hazard（`ward`/`pillar`/`core`）在跨段 / 真死 / Boss 接力 / respawn 处必须清
   （现有 `game.hazards=[]` 五处自动覆盖，确认没有旁路）。
6. `_engMkBoss` 初始化全部新字段：`chargeN/leechOn/quellDmg/quellDur/quellFlash/coreOn`。
7. UI 所有新字段必须缺失守卫（`(b.leechOn||0)`），缺字段退回旧渲染，不许抛异常。
8. `_bossIdx` 上限 4→5，`BOSS_NAME` 加第 6 项，部件表/白剪影表同步回落链。
