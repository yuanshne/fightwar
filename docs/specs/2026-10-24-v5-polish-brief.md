# v5 大翻新设计输入书（给 GLM-5.3 设计师）

> 玩家实测反馈（原文）："技能不够有趣，O技能不知道在干嘛，跳跃改成有两段跳就可以了，
> 整体风格比较丑，可以优化一下，原神画风就可以，关卡有点少，整体也有点无趣，
> 打击感移动感很差，封面也不吸引人。"
> 分工：GLM-5.3 设计（本工单读者），GLM-5.3-Flash 施工（两波）。基线：v4（7关+Boss+技能+谜题）。

## 一、"原神画风"的像素化转译（重要：统一美术北极星）

不是做 3D，是把它的高辨识特征转译进像素画，所有美术决策对齐这四条：
1. **高饱和明亮幻想色**：晴空蓝 #4a9fe8 系、翡翠绿、落日橙金；暗部不脏（提蓝紫而不是压黑）；
2. **cel-shading 三阶硬边**：亮/固有色/影三色阶干净分块，**大幅减少 v2.5 的棋盘抖动**（抖动=复古风，与原神风冲突，仅保留在远景空气感处）；
3. **发光元素感**：关键物件带 1-2px 亮边光晕（金币、技能、Boss 眼睛、神龛）；粒子走"流光"（细长、拖尾）而不是方点；
4. **UI 原神化**：半透明深蓝底 + 金色细描边 + 圆角切角（HUD/菜单/谜题面板统一换皮）。

## 二、手感重做（第一波，引擎+界面+特效素材）

### 二段跳（替换现跳跃体系的核心）
- 地面跳=现行为；**空中再按跳=二段跳**：vy=-jumpV*0.92，主角做空翻动画帧+白色气环粒子；
- 二段跳次数 1，落地/弹簧/踩踏/受击重置；弹簧弹跳中不消耗也不给二段跳；
- 土狼时间只对第一段有效；二段跳不吃长按变高（固定高度）；
- **全部 10 关（含新关）难度重校验**：原按单跳设计的跳距/高度全部重新核对（间隙≤4 也可，因为有二段跳；但新关设计必须让二段跳"有用而非必须"）。

### 打击感清单（逐项落地，完成一项打一个勾）
- hit-stop 0.06→**0.10s**，且冻结期间命中火花仍渲染（用 UI 层粒子绕过冻结）；
- 命中击退：敌人被击退 40px+受击白闪 0.15s+受击抖动；Boss 命中部位微后退；
- **伤害数字**：新 game.floats 浮动文字系统（伤害值/金币+5/COMBO 弹字统一走它），
  数字弹跳上浮渐隐，普通白/暴击金/技能青；
- 挥击视觉升级：更大弧光（含起手帧-挥击帧-余韵帧）+命中的星形火花 4-6 粒；
- 震屏分级：小命中 2 / 击杀 4 / 大招 8，带 0.05s 起振延迟；
- 音效重调：挥击加"呼啸+命中"双段、击杀加低频冲击。

### 移动感清单
- 空中操控性：空中加速度 = 地面 0.75×，转向更快（惯性减半）；
- 落地分级反馈：小落灰尘 4 粒+微 squash；大落（vy>300）尘 10 粒+squash 加深+轻震屏 2+落地声加重；
- 跑步：脚步尘土每 0.18s 一粒 + 跑动身体前倾 2°（渲染层倾斜）+ 转身瞬间翻转 squash；
- 冲刺：起手 0.05s 后仰蓄力帧 → 爆发（速度线+风粒子）→ 结束滑行 0.1s 缓冲，不再是"匀速滑块"。

## 三、技能重做（第一波）

- **O·流星连斩（重做重点，解决"不知道在干嘛"）**：释放瞬间**时停 0.3s（全屏暗+主角高亮）**
  → 超大十字星剑光斜扫全屏 → 屏幕内敌人逐个弹出伤害数字+击飞 → 冲击波环从主角扩散 →
  白闪 0.1s 收尾。全程 1.2s 演出感，玩家一眼看懂"我放了个大的"；
- **U·星陨术**：增加落点瞄准圈（地面金色圈 0.5s）→ 星体拖尾坠落 → **落地爆坑+冲击尘+伤害数字**；
- **I·星光护盾**：护盾有清晰六边形光罩+流动光纹，被击破时"碎裂"音效+玻璃碎粒子，
  剩余 1s 时闪烁提示；
- 技能栏图标化：三个技能各有专属小图标（星/盾/剑），冷却扫描+就绪时金色呼吸光。

## 四、关卡扩充（第二波）：7 → 10 关

新增三关（主题由设计师定，建议方向：翡翠风谷=上升气流与风车机关、落日王城=城堡+吊灯+
骑士盔甲敌、星空回廊=重力反转或传送门，选可确定性实现的）：
- 每关 ≥1 种**新机关**（上升气流 'w'：恒定上升风区，二段跳配合抵达高处；其余由设计定）；
- 难度按二段跳体系重校；每关仍有神龛（新谜题数据，数织画稿配新主题）；
- Boss 关保持第 7 关，新三关排在 Boss 后作为"终章篇"（10 关通关=真结局致谢屏）。

## 五、封面重做（第二波）

- key visual 构图：主角跃起剪影（背光金边）vs 远景 Boss 巨影对峙，中间星空+流星；
- 动态 logo："像素勇者"四字逐字弹入+落星拖尾，副标 PIXEL QUEST 金属渐变；
- 背景：三层视差云海+缓慢星移+偶尔流星；任意键提示改为呼吸光按钮样式；
- 菜单统一原神化 UI 皮肤。
